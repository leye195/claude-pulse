# Claude Pulse

Claude Code 사용 통계를 시각화하는 Electron 데스크톱 앱.

## 기술 스택

Electron 41 · React 19 · TypeScript (Strict) · Vite 5 · Recharts 3 · Tailwind CSS 4 · TanStack Query 5 · Vitest · electron-builder

## 주요 명령어

```bash
npm run dev          # 개발 서버 + Electron 실행
npm run build        # 프로덕션 빌드
npm run package      # Electron 앱 패키징
npm test             # 테스트 실행 (vitest run)
npm run test:watch   # 테스트 워치 모드
```

## UI 언어

- 모든 라벨, 버튼, 메시지는 한국어
